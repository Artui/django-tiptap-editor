django-tiptap-editor — keyboard harness

A no-build page for exercising Enter / Shift-Enter against the committed bundle. The playground mounts a real editor the way the Django widget does (a <textarea> carrying data-tiptap-config); the scenario grid runs the same key presses across all three enterKey modes and asserts the serialized HTML.
